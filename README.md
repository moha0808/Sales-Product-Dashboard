

## 📌 Project Overview

This dashboard provides comprehensive business insights into sales trends, product category contributions, profit margins, and regional performance. It enables stakeholders to identify top-performing products, seasonal trends, and opportunities for revenue optimization.

---

## 🛠️ Tech Stack & Tools

- **Power BI Desktop:** Data modeling, DAX measures, interactive visualizations, and reporting.
- **SQL:** Data querying, aggregation, and transformation (`Data.sql`).
- **Power Query:** ETL processes, data cleaning, and relationship setup.

## 🔑 Key Insights & Features

- **KPI Metrics:** Total Sales Revenue, Total Profit, Profit Margin (%), Units Sold, and Return Rates.
- **Product & Category Performance:** Breakdown of revenue and profitability across product lines and sub-categories.
- **Trend & Seasonality Analysis:** Monthly and quarterly performance metrics to monitor growth over time.
- **Interactive Slicers:** Dynamic filtering by Date/Period, Region, Product Category, and Customer Segment.

## 🚀 Getting Started

1. **Clone the repository:**
```bash
git clone [https://github.com/moha0808/Sales-Product-Dashboard.git](https://github.com/moha0808/Sales-Product-Dashboard.git)

```


2. **Review the Data:**
* Execute the queries inside `Data.sql` in your SQL database environment to inspect the underlying schema and tables.


3. **Open the Dashboard:**
* Open `Sales & Product DashBoard.pbix` in [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
* Refresh the data source if connected to a local database, or explore the pre-loaded report views.
